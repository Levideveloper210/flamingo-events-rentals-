# Flamingo Events and Rentals website

A static website (HTML, CSS, JavaScript). No build step.

## Push to GitHub
```
git init
git add .
git commit -m "Flamingo Events and Rentals website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/flamingo-events-rentals.git
git push -u origin main
```

## Deploy on Vercel
1. On vercel.com choose **Add New > Project** and import the GitHub repo.
2. Set Framework Preset to **Other**. Leave build command and output directory empty.
3. Click **Deploy**. Every push to `main` redeploys.

## Edit
- Text and sections: `index.html`
- Colours: variables at the top of `style.css`
- WhatsApp number: top of `script.js`
